# 裸机编程指南 · 知识库主页

本知识库由 [bare-metal-programming-guide](https://github.com/cpq/bare-metal-programming-guide) 仓库的 `README_zh-CN.md` 拆分改造而来，可直接导入 Obsidian 使用。教程以 **STM32 Nucleo-F429ZI** 开发板贯穿全程，从零开始用 GCC 编译器和数据手册裸写固件，帮助你理解 STM32Cube、Keil、Arduino 等框架/IDE 的底层原理。

## 文档导航

### 基础概念
- [[00-简介]] — 指南简介、涵盖话题、开发板、工具链配置
- [[01-存储与寄存器]] — 32 位地址空间、外设寄存器、直接寄存器编程
- [[02-GPIO与引脚]] — 用结构体重写外设寄存器、GPIO 抽象 API、引脚编号
- [[03-启动代码与链接]] — 中断向量表、最小固件、链接脚本、启动代码、烧写固件

### 构建与外设
- [[04-Makefile构建]] — make 构建自动化、编译/烧写目标、clean
- [[05-LED闪烁]] — GPIO 输出模式、RCC 时钟使能、BSRR 开关引脚（step-1）
- [[06-SysTick定时器]] — SysTick 中断、精确毫秒计时、非阻塞主循环（step-2）
- [[07-UART串口]] — 串口外设配置、替代功能、读写、终端调试输出（step-3）

### 进阶

- [[10-CMSIS]] — 供应商 CMSIS 头文件替换手写定义（step-5）
- [[11-时钟配置]] — PLL、Flash 延迟、APB1/APB2 预分频、180MHz 配置（step-6）

### 综合项目

## 学习路径建议

1. 先读 [[00-简介]] 配置好工具链。
2. 按 `01 → 02 → 03 → 04` 顺序建立「存储/寄存器 → 启动 → 链接 → 构建」的地基。
3. 然后按 `05 → 06 → 07 → 08` 让固件「动起来 → 计时 → 输出 → 打印调试」。
4. 最后依次学习 `09 → 10 → 11 → 12`，从调试技巧到使用供应商头文件、配置时钟，再到完整的网络服务器项目。
