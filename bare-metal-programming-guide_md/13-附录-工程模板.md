# 13 · 附录 · 工程模板

> 本附录概括说明仓库 `templates/` 目录下的内容。这些模板是从教程中提炼出的可复用工程骨架，可按需选择。

`templates/` 目录包含三类模板，每类下按板卡分子目录。每个子目录结构大致相同：`Makefile`、`hal.h`、`link.ld`、`main.c`，部分还有 `syscalls.c`、`startup.c`、`sysinit.c`（`cli` 与 `lfs` 类别较新的板卡）。

## blinky —— 最简 LED 闪烁模板

强调"任务式"的非阻塞主循环，同时管理 LED 闪烁与周期性日志两个任务。

支持板卡：
`esp32-c3`、`frdm-mcxw71`、`nRF52840dk`、`nucleo-f429zi`、`nucleo-l432kc`、`nucleo-u5a5zj-q`、`same54-xplained`

`main.c` 核心模式（以 `nucleo-f429zi` 为例）：

```c
#define BLINK_PERIOD_MS 500  // LED blinking period in millis
#define LOG_PERIOD_MS 1000   // Info log period in millis

uint32_t SystemCoreClock;  // Required by CMSIS. Holds system core cock value
void SystemInit(void) {    // Called automatically by startup code
  clock_init();            // Sets SystemCoreClock
}

static volatile uint64_t s_ticks;  // Milliseconds since boot
void SysTick_Handler(void) {       // SyStick IRQ handler, triggered every 1ms
  s_ticks++;
}

static void led_task(void) {  // Blink LED every BLINK_PERIOD_MS
  static uint64_t timer = 0;
  if (timer_expired(&timer, BLINK_PERIOD_MS, s_ticks)) {
    gpio_toggle(LED_PIN);
  }
}

static void log_task(void) {  // Print a log every LOG_PERIOD_MS
  static uint64_t timer = 0;
  if (timer_expired(&timer, LOG_PERIOD_MS, s_ticks)) {
    printf("tick: %5lu, CPU %lu MHz\n", (unsigned long) s_ticks,
           SystemCoreClock / 1000000);
  }
}

int main(void) {
  gpio_output(LED_PIN);
  uart_init(UART_DEBUG, 115200);

  for (;;) {
    led_task();
    log_task();
  }

  return 0;
}
```

## cli —— 命令行交互模板

在 blinky 基础上增加了命令行解释器，可交互式地执行 `hexdump`、`led`、`reboot` 等命令，适合做调试诊断。

支持板卡：`nucleo-f429zi`、`nucleo-l432kc`

`main.c` 核心片段：

```c
static void cli_prompt(void) {
  printf("enter command:\n");
}

static void cli_usage(void) {
  putchar('\n');
  printf("COMMANDS:\n");
  printf("  hexdump ADDR LENGTH\n");
  printf("  led <on|off|blink MILLIS>\n");
  printf("  reboot\n");
}

static void cli_led(const char *arg1, const char *arg2) {
  if (strcasecmp(arg1, "on") == 0) {
    s_led_blink = 0;
    gpio_write(LED, true);
    // ...
  }
}
```

## lfs —— 集成 LittleFS 闪存文件系统模板

在 blinky 基础上集成了 [LittleFS](https://github.com/littlefs-project/littlefs) 闪存文件系统，可读写文件、列目录，并持久化数据（如 `boot.txt` 记录启动次数）。需要额外的 `sys/dirent.h` 头文件适配。

支持板卡：`nucleo-f303k8`、`nucleo-h563zi`、`nucleo-l432kc`

`main.c` 核心片段：

```c
#include <dirent.h>
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>

#include "hal.h"

#define DATA_DIR  "/data"
#define DATA_FILE DATA_DIR "/boot.txt"

static inline void list_files(const char *path) {
  if (path == NULL || path[0] == '\0') path = ".";
  DIR *dirp = opendir(path);
  if (dirp != NULL) {
    struct dirent *dp;
    while ((dp = readdir(dirp)) != NULL) {
      // ... 遍历目录项
    }
  }
}
```

- 各子目录的板卡差异主要体现在 `hal.h`（寄存器地址、时钟、引脚定义）与 `link.ld`（存储布局）——这正是教程前几章讲解的核心概念在不同 MCU 上的应用。
- 教程主线（[[00-主页]] 至 [[12-Web服务器]]）使用的是 `step-0` 到 `step-7` 目录，本附录的 `templates/` 则是把这些经验固化为可复用的工程骨架。
